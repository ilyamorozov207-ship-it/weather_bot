# Weather Bot 🌤️

Telegram-бот для получения текущей погоды по названию города.

Бот получает координаты города через Open-Meteo Geocoding API, затем получает актуальные погодные данные через Open-Meteo Weather API и отправляет пользователю информацию о погоде.

## Возможности

- 🔎 Поиск города по названию
- 🌡 Текущая температура
- 🤗 Ощущаемая температура
- 💨 Скорость и направление ветра
- 💧 Влажность
- ☁ Облачность
- 🌧 Количество осадков
- 🌤 Описание погодных условий

## Используемые технологии

- Python 3.13
- aiogram 3.x
- requests
- Open-Meteo API
